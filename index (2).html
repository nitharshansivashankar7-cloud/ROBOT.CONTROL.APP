Robot Controller

Drive robots on Arduino, ESP32, ESP8266, Raspberry Pi Pico and similar boards over USB, Bluetooth or Wi-Fi.

Drive

Hold a button to move, release to stop. Keyboard: arrow keys or WASD, space to stop.

Starter firmware

Flash this to an Arduino or ESP32 with an L298N driver. It understands the default command map. Change the pins to match your wiring.




ESP32 Wi-Fi firmware


Runs a WebSocket server on port 81 and understands the same commands, including the joystick. Install the "WebSockets" library by Markus Sattler, use ESP32 core 3.x, then enter the IP shown in the Serial Monitor as ws://IP:81. Browsers block ws:// addresses from https pages, so this works best when this page is saved and opened as a local file, or served from your own network. From this hosted page, use USB or Bluetooth.
